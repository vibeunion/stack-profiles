# admin-svadmin

Use this profile for internal users who manage data, workflows, staff access, and audits.

- Use svadmin resources, providers, RBAC, and audit integrations instead of rebuilding CRUD screens in a public application.
- Use the SupaCloud data provider and keep authorization server-side and RLS-backed.
- Use SupaOAuth when the application needs organization governance, hosted login, or audit administration.
