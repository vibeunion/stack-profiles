# web-nuxt

Use this profile for public browser applications that need SSR, SEO, content routes, or a customer portal.

- Use Nuxt routing, server features, and data loading conventions.
- Use Tailwind CSS and Nuxt UI. Do not introduce UnoCSS or mini-program UI packages.
- Use `@supabase/supabase-js` for browser-facing SupaCloud access.
- Keep secrets and service-role access on server routes or Edge Functions.
